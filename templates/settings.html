F12 参数查找指南

学校系统更新后，按以下步骤查找所有需要的参数

  1. 浏览器打开 jwxt.shu.edu.cn 并登录
  2. 按 F12 → Network（网络） 标签
  3. 刷新页面，点击第一条请求
  4. 在 Request Headers 里找到 Cookie:
  5. 复制其中 JSESSIONID=xxx 和 route=xxx 的值

或者用上面的「一键获取 Cookies」书签工具更方便

  1. 登录教务系统，进入选课页面
  2. 按 F12 → Network（网络）
  3. 在搜索框输入任一课程号，点查询
  4. 找到请求名为 cxJxbWithKchZzxkYzb 的 POST 请求
  5. 在 Request Payload / Form Data 里找：
    • xkxnm — 学年（如 2025 = 2025-2026学年）
    • xkxqm — 学期码

xkkz_id（选课控制ID） 是最关键的参数之一，每个选课轮次都会变化。

  1. 在查询课程的 POST 请求的 Form Data 里查找 xkkz_id
  2. 复制它的值，在本页「修改配置参数」中更新

其他常用参数 同样在 Form Data 里：

  • jg_id — 学院ID
  • zyh_id — 专业ID
  • bh_id — 班级ID
  • njdm_id — 年级代码

  1. 在查询课程的POST请求的 Response 标签里查看返回数据
  2. 每个教学班有一个 jxb_id 字段
  3. 抢课功能需要用到这个ID
  4. 你也可以直接在本系统的「课程监控」页面查课程，会显示 jxb_id
