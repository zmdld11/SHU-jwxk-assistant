# 上大选课监控和抢课助手 🎓

基于 Python 开发的上海大学教务系统选课监控及辅助抢课工具，具有美观简洁的 Web 图形化操作界面。可以实现教务系统课表的获取、自定义美化展示、课程余量监控。

## 🌟 功能特性

- **可视化课表展示**：从教务系统一键读取本学期课表，支持按**全部 / 前八周 / 后八周**进行快速筛选，完美适配不同的周数变化。
- **课表网格自适应**：智能排版多节连上的情况，前八周与后八周并排分栏展示更直观。
- **容量与余量监控**：自动获取你在系统的选课清单里的课程剩余名额与班级详细信息。
- **自动抢课**：搜索课程 → 选择教学班 → 系统自动监控空位，检测到冲突自动跳过，有空位且无冲突时自动选课。
- **优雅的 Web 管理页面**：马卡龙高颜值卡片排版、响应式布局、丝滑切换动画体验。

## � 运行环境要求

- **Python 版本**：官方推荐使用 **Python 3.8 ~ 3.12** 及以上版本。
- **环境隔离保障**：本项目内置使用标准 `venv` 建立**独立虚拟环境**，所有依赖库均会安全地安装在项目文件夹内局部的 `.venv` 中，**绝对不会**自动装到你的全局 base 环境里污染其他系统级 Python 依赖。

## �🚀 快速开始

如果你是零基础或者不想手动敲命令代码，本项目全程提供了极其便捷的 `.bat` 自动操作脚本。

### 1. 下载项目源码
- **通过 Git 获取（推荐）**：打开终端并运行以下命令：
  ```bash
  git clone https://github.com/zmdld11/SHU-Course-Helper.git
  cd SHU-Course-Helper
  ```
- **直接下载**：如果你没有安装 Git，请点击页面右上角绿色的 **Code** 按钮，选择 **Download ZIP**。下载完成后进行解压缩，并进入解压好的文件夹。

### 2. 安装环境与配置（初次使用）
- 确保你已经安装了所需版本的 **Python**。
- 双击运行根目录下的 `安装环境.bat` 脚本。该脚本会：
  1. 自动进行检测并在当前目录创建隔离的 `.venv` 虚拟环境。
  2. 自动切换至虚拟环境，并通过清华国内镜像加速下载所有所需的依赖库。
  3. 自动根据 `.env.example` 模板为你生成一份 `.env` 配置文件。
- **重要配置步骤**：在系统设置中按照右侧教程将所需值复制到输入框中点击保存即可。

### 3. 启动系统
- 双击根目录下的 `启动系统.bat`。
- 程序启动后，控制台会输出一个本地 Web 地址（例如：`http://127.0.0.1:5000`）。
- 复制并在你的浏览器中打开该地址，即可进入监控图形面板。
