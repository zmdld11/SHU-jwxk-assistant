# 上大选课监控和抢课助手 🎓

基于 Python 开发的上海大学教务系统选课监控及辅助抢课工具，具有美观简洁的 Web 图形化操作界面。可以实现教务系统课表的获取、自定义美化展示、课程余量监控。

## 🌟 功能特性

- **可视化课表展示**：从教务系统一键读取本学期课表，支持按**全部 / 前八周 / 后八周**进行快速筛选，完美适配不同的周数变化。
- **课表网格自适应**：智能排版多节连上的情况，前八周与后八周并排分栏展示更直观。
- **容量与余量监控**：自动获取你在系统的选课清单里的课程剩余名额与班级详细信息。
- *抢课辅助功能（开发中）*：当课程出现余量时，将尝试提供便捷加课接口及通知服务。
- **优雅的 Web 管理页面**：马卡龙高颜值卡片排版、响应式布局、丝滑切换动画体验。

## 🚀 快速开始

如果你是零基础或者不想手动敲命令代码，本项目全程提供了极其便捷的 `.bat` 自动操作脚本。

### 1. 下载项目源码
- **通过 Git 获取（推荐）**：打开终端并运行以下命令：
  ```bash
  git clone https://github.com/your-username/SHU-Course-Helper.git
  cd SHU-Course-Helper
  ```
- **直接下载**：如果你没有安装 Git，请点击页面右上角绿色的 **Code** 按钮，选择 **Download ZIP**。下载完成后进行解压缩，并进入解压好的文件夹。

### 2. 安装环境与配置（初次使用）
- 确保你已经安装了 **Python**。
- 双击运行根目录下的 `安装环境.bat` 脚本。该脚本会自动使用国内镜像加速下载所有所需的依赖库，并会自动根据 `.env.example` 模板为你生成一份 `.env` 配置文件。
- **重要配置步骤**：可以根据系统中系统设置的一键获取Cookies工具快速获取.env信息，也可以使用文本编辑器（如记事本、VS Code）打开刚刚生成的 `.env` 文件，填入你个人的教务系统 `JSESSIONID` 和 `route` 等 Cookie 关键信息（可登录教务系统后按 `F12` 从开发者工具中获取）。

### 3. 启动系统
- 双击根目录下的 `启动系统.bat`。
- 程序启动后，控制台会输出一个本地 Web 地址（例如：`http://127.0.0.1:5000`）。
- 复制并在你的浏览器中打开该地址，即可进入监控图形面板。
